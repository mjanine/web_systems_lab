# Personal Portfolio Website

A modern, responsive developer portfolio built with **React** and **Vite**, showcasing my featured projects, certifications, technical skills, and background in data analytics and computer science.

---

## ✨ Features

- **Interactive Hero Section:** Dynamic video background with custom header navigation.
- **Project Showcase:** Highlights key projects with detailed descriptions, tags, and visuals.
- **Certifications Grid:** Evenly aligned, responsive grid featuring hover animations and zoom effects.
- **Languages & Tools:** Interactive skill pills organized into **Languages** and **Data & Analytics Tools** with hover highlight animations.
- **Responsive Design:** Optimized layout scaling across various desktop and laptop screen sizes.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3 (Modern Flexbox & Grid)
- **Build Tool:** Vite
- **Icons & Visuals:** Custom SVGs and local assets
